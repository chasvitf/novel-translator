# Novel Lock · แปลนิยายด้วย AI แบบชื่อไม่เพี้ยน

เว็บแอปแปลนิยายทีละหลายตอน ล็อกชื่อตัวละคร สถานที่ และวิชาด้วยอภิธานศัพท์ เพื่อให้ทุกตอนใช้คำเดียวกัน ใช้ AI ฟรี (Google Gemini) ได้

**ลองใช้:** https://novel-th.vercel.app

## ทำอะไรได้

- **หลายภาษา**: ต้นฉบับจีน ญี่ปุ่น เกาหลี อังกฤษ เวียดนาม อินโดนีเซีย ฯลฯ แปลเป็นไทยหรือภาษาอื่น ตรวจภาษาต้นฉบับให้อัตโนมัติ
- **นำเข้า** .txt (UTF-8, GB18030, Big5, Shift_JIS, EUC-KR, TIS-620) .docx .epub หรือวางข้อความ แล้วแยกตอนจากหัวข้อ เช่น `第12章` `제12화` `第3話` `Chapter 12` `Chương 12` `ตอนที่ 12` หรือคั่นด้วยบรรทัด `===`
- **อภิธานศัพท์**: ทุกตอน AI จะหาชื่อและคำเฉพาะใหม่ให้ (ล็อกเลย หรือรอให้ยืนยันก่อน) แก้ เพิ่ม ลบได้ และนำเข้าหรือส่งออก CSV ได้ ถ้าเปลี่ยนคำแปล จะเลือกเปลี่ยนในตอนที่แปลไปแล้วได้ด้วย
- **แปลให้ชื่อไม่เพี้ยน**: แต่ละท่อนส่งให้ AI เฉพาะคำในอภิธานศัพท์ที่มีอยู่ในท่อนนั้น (ถ้าส่งไปทั้งหมด โมเดลเล็กจะใส่ชื่อที่ไม่มีในประโยคลงไป) พร้อมเรื่องย่อของตอนก่อนหน้าและท้ายตอนที่แล้ว เพื่อให้ AI รู้บริบท
- **ตรวจอัตโนมัติ**: หลังแปล โปรแกรมเช็กว่าคำในอภิธานศัพท์ทุกคำแปลตรง และไม่มีต้นฉบับหลุดมาโดยไม่ได้แปล ถ้าเจอปัญหาจะให้ AI แก้เฉพาะจุด (ทำซ้ำได้ไม่เกิน 2 รอบ)
- **ขัดเกลา** อีกรอบได้ (เลือกเปิดเอง) · แนวเรื่อง 8 แบบกำหนดสำนวนและสรรพนาม · เลือกวิธีเขียนชื่อจีน (จีนกลาง / แต้จิ๋ว-ฮกเกี้ยน / แปลความหมาย) และคำเรียกขานแบบญี่ปุ่นหรือเกาหลี
- **อ่านและแก้**: ดูต้นฉบับคู่คำแปล ไฮไลต์คำในอภิธานศัพท์ แก้คำแปลเองได้
- **ส่งออก** .docx .epub .txt .md .zip (แยกตอน) และไฟล์ต้นฉบับคู่คำแปล · สำรองและกู้คืนโปรเจกต์เป็น .json

## AI ที่รองรับ

| ผู้ให้บริการ | ค่าใช้จ่าย | สถานะ |
|---|---|---|
| Google Gemini | ฟรี (ต้องมี key) โควตาประมาณ 20 ครั้งต่อวันต่อโมเดล เมื่อหมดระบบจะสลับไปโมเดลถัดไปให้เอง | ทดสอบแล้ว |
| Pollinations | ฟรี ไม่ต้องมี key จำกัด 1 ครั้งต่อ 30 วินาที | ทดสอบแล้ว |
| Groq, OpenRouter (โมเดล `:free`) | ฟรี (ต้องมี key) | ยังไม่ได้ทดสอบกับ key จริง |
| OpenAI, Anthropic Claude | เสียเงิน | ยังไม่ได้ทดสอบกับ key จริง |
| OpenAI-compatible / Ollama ในเครื่อง | แล้วแต่ผู้ให้บริการ | ยังไม่ได้ทดสอบ |

API key เก็บใน `localStorage` ของเบราว์เซอร์ และส่งตรงไปที่ผู้ให้บริการ AI ไม่ผ่านเซิร์ฟเวอร์ของเว็บนี้ ส่วนนิยายกับคำแปลเก็บใน IndexedDB ของเครื่อง

## โครงสร้าง

เป็นเว็บ static ไม่ต้อง build

```
public/
  index.html, css/app.css, js/app.js     หน้าเว็บ
  js/lib/split.js       แยกตอน แบ่งท่อน
  js/lib/glossary.js    อภิธานศัพท์ ค้นคำ ตรวจคำแปล CSV
  js/lib/prompts.js     prompt แปล / ขัดเกลา / แก้ / หาคำใหม่
  js/lib/pipeline.js    ขั้นตอนแปลหนึ่งตอน
  js/lib/providers.js   เรียก AI แต่ละเจ้า, เว้นระยะ, retry, สลับโมเดลเมื่อโควตาหมด
  js/lib/files.js       นำเข้า/ส่งออกไฟล์
  samples/              โปรเจกต์ตัวอย่าง (นิยายหมดลิขสิทธิ์ แปลด้วยโปรแกรมนี้)
scripts/                ดึงและทำความสะอาดชุดทดสอบ, แปลชุดทดสอบ, สร้างตัวอย่าง
tests/                  node --test
```

```bash
npm test                                   # unit tests
python3 -m http.server -d public 8765      # เปิดที่ http://localhost:8765
# แปลชุดทดสอบด้วยนิยายจริง (ใส่ GEMINI_API_KEY ใน .env)
node scripts/run_corpus.mjs gemini gemini-3.5-flash xiyouji rashomon
```
